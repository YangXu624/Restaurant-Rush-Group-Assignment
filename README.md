# Restaurant Rush

Java CLI restaurant management group assignment. This is the initial Stage 1
skeleton; it is not a playable game yet. The main implementation reference is
[the class contracts](docs/class-contracts.md), including member ownership.

## Build and run

Install a JDK 17 or newer and make `javac` and `java` available on your PATH.
The scripts target Java 17 for record support and require a POSIX shell
(macOS, Linux, or WSL). No build tool or external libraries are needed.

```sh
./compile.sh
./run.sh
```

`run.sh` recompiles before launching `restaurantrush.Main`. Both scripts also
work when invoked by path from another directory. Generated files go in `build/`.
The entry point prints a skeleton status message and exits successfully; it does
not construct or invoke unfinished game objects.

## Source layout

```text
src/restaurantrush/
  Main.java
  boundary/   RestaurantCLI
  control/    GameController, TurnManager
  entity/     Restaurant, Customer, Table, Order, MenuItem,
              CustomerStatus, OrderStatus
  staff/      Waiter, Chef, Cashier
  support/    ActionResult, GameSnapshot, CustomerView, TableView
```

All declared operations and explicit constructors are stubs throwing
`UnsupportedOperationException`, including getters and record constructors.
Enums contain the agreed constants; record accessors are generated by Java.
Attributes are declared but their initialization is left to each class's owner.
No game rules, validation, transitions or collaborator wiring are implemented.

## Details still to agree

- Constructor signatures and collaborator wiring for `RestaurantCLI` and
  `TurnManager`. No explicit constructors have been added for these classes;
  Java supplies default no-argument constructors for now.
- How end-of-turn displays obtain completed turns, since `finishTurn()` advances
  before returning and the snapshot has only the current turn.
- Exception/null handling for invalid domain calls, repeated abandonment, and
  whether customer/order IDs must be 1–6 or any positive integer.
- Whether snapshots include all historical customers or only active customers.
- Confirm Java 17 as the team's target; it is the current script setting.

These open items are documented in contract Section 9. The contract document
has not been changed by this skeleton setup.
